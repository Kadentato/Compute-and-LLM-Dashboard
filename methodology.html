The tracker measures the share of tokens routed through public AI gateways that go to open-weight versus closed-frontier models, daily, with no manual data entry. This page states what is measured, how models are classified, and what the numbers cannot say.

What it measures — and what it does not

Gateway traffic is developer and application traffic: agents, coding tools, SaaS products, hobby projects. Consumer chat (ChatGPT, Gemini, Claude.ai, Grok) never touches a gateway, and no lab publishes model-level token counts. There is no public source for "share of all tokens in the world," and this tracker does not pretend to have one. The closest automatic consumer signal — Cloudflare Radar's DNS popularity ranking — is shown as rank order only, because that is all it is.

Classification rules

Open weight means the model's weights are downloadable under any licence, including non-commercial. Key decisions, tagged per model rather than per lab:

  • gpt-oss counts as open although OpenAI is otherwise closed; Gemma counts as open although Gemini is closed.
  • Mistral is split per model: released-weights models are open; API-only models (Large, Medium, Codestral 25xx, Ministral 3B) are closed.
  • Cohere's Command-R family is open (downloadable, CC-BY-NC); its North platform models are closed.
  • Cloaked pre-release models (openrouter/*-alpha, stealth/*) are tagged unknown, not guessed.
  • Each gateway's aggregated remainder ("other" / "Other") cannot be classified and is shown as unattributable, never allocated.

The full mapping lives in model_classification.json, versioned in the repository so every reclassification is visible in history. Models the table does not yet cover appear in the "unmapped" notice on the full tracker page — the table maintains itself by exception.

Known limitations

  • Top-N truncation. Both gateways name only their top models. On Vercel this is severe: before May 2026, open-weight usage sat inside the unnamed "Other" bucket, so the early open-share line is a floor, not a measurement.
  • Gateway selection bias. OpenRouter skews cost-sensitive and hobbyist; Vercel skews production apps. The spread between them is a finding, and the two series are never blended.
  • Coverage gaps. Text tokens only (image/video generation is excluded); no visibility into direct-to-lab API traffic (apps calling OpenAI or Anthropic without a gateway); Vercel publishes shares with no absolute volumes.
  • Headline denominator. Share figures are percentages of classifiable tokens; the composition charts show how much is excluded each day.

Pipeline

A stdlib-Python collector runs via GitHub Actions on several scattered daily schedules (GitHub's scheduler is best-effort, so redundant slots plus backfill make timing irrelevant — a run that fetches nothing new commits nothing). Every raw response is stored verbatim under data/raw/<source>/<date>.json before any processing. The collector is idempotent, backfills missing days, fails loudly rather than writing empty data, and its classification and derivation logic is covered by a CI test suite. The site is static — a dashboard homepage plus this full analysis page — and every chart offers its data as CSV.
